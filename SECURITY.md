# Security Policy

## Supported Versions

Security fixes are applied to the latest state of the `main` branch.

| Branch | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately using GitHub's **Report a vulnerability** feature under the **Security** tab of this repository (`edwin-dev31/rafaga`).

Please include as much of the following information as possible:
- Description of the vulnerability and potential impact (e.g., cross-tenant data access, authentication bypass, privilege escalation, SSRF, or media/R2 access issue).
- Steps to reproduce or a minimal proof of concept.
- Affected modules, endpoints, or configuration files.

## Response Expectations

- We aim to acknowledge receipt of a security report within **72 hours**.
- Once confirmed, we will work on a fix and coordinate disclosure before publishing details.
- Never include real production credentials, tokens, or customer data in reports.
